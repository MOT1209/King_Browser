1. ملخص المشروع

متصفح سطح مكتب (Electron 43 + React 18 + TypeScript + Vite) مع خادم MCP محلي، WebGPU/Whisper، حظر إعلانات، تبويبات LRU، مزامنة E2EE، دعم إضافات Chrome.

2. ما وجدته (Findings)

  • In-progress 19 ملفًا معدّلًا + 9 ملفات جديدة غير مُلتزم بها (refactor groß).
  • Sync EmailVerificationRequiredError + key rotation + previousMasterKey.
  • Security isTrustedSender صارم؛ child_process 8 استدعاءات cần path validation.
  • Build tsc --noEmit يمر؛ لا TODO/FIXME في src/electron.
  • Risk تغيير syncService requires integration tests.
